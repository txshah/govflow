# lib/

Client-side helpers for the web app.

**Inputs**

- Env / connection config

**Outputs**

- Shared hooks and utilities

`module_bindings/` is generated from `spacetimedb/` (see its README for the command); never edit it by hand.
Demo sign-ins use the per-person tokens in `seed/.demo-tokens.json` (see `seed/README.md`).
